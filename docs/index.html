02 / COMMAND LINE

ONE COMMAND. WHOLE WORKSHOP.

The jupy CLI drives everything — server, themes, environments, packages, notebooks. Click any line to copy it.

  jupy — powershell
PS> pip install jupy-notebook # the whole notebook server⧉ copy
PS> jupy # serve on :8000, opens your browser⧉ copy
PS> jupy theme add nord-frost --use # community themes⧉ copy
PS> jupy env create datasci # isolated environment⧉ copy
PS> jupy pip install numpy pandas # into the active env⧉ copy
PS> jupy run report.ipynb -o executed.ipynb # headless execution⧉ copy
PS> jupy export report.ipynb --format html # or py / md / pdf⧉ copy
PS> jupy doctor --full # health check⧉ copy

WINDOWS TERMINAL USERS → pip install "jupy-notebook[terminal]" FOR FULL CONPTY SUPPORT

CALL FOR
THEMES 📣

Ship your own theme

Scaffold locally with jupy theme new my-theme, tune theme.yml + about.json, drop in a preview.png, and open a PR to themes_jupy. GitHub Actions validates and publishes it to the registry automatically — then anyone can jupy theme add my-theme.

05 / GET STARTED

THREE STEPS. ZERO CLOUD.

01

Install

One package. Python 3.9+, any OS. Windows users: add the terminal extra for full ConPTY support.

$ pip install "jupy-notebook[all]"

OR MINIMAL → pip install jupy-notebook

02

Launch

Run it in any project folder. The server starts on port 8000 and opens your browser — everything is served from that folder, and SAVE writes notebooks right back into it.

$ cd my_project && jupy

HEADLESS → jupy serve --no-browser --port 9000

03

Build

Write a cell, hit Shift+Enter. Install a theme, spin up an environment, open the terminal — it's all already there.

$ jupy theme add nord-frost --use

HEALTH CHECK → jupy doctor --full
